# نظام حجز التغطيات الإعلامية والتصوير - مجموعة مدارس الأوائل الأهلية

نظام إلكتروني لإدارة وحجز التغطيات الإعلامية لمدارس مجموعة الأوائل الأهلية الست، مزود بنظام قفل الفترات التلقائي، وإشعارات فورية للهاتف عبر تيليجرام وواتساب، ولوحة تحكم محمية مخصصة لمدير قسم الإعلام.

## المدارس المعتمدة:
1. ابتدائية الأوائل الأهلية (أحمر)
2. ثانوية الأوائل الأهلية للبنين (أصفر كموني)
3. ثانوية الأوائل الأهلية للبنات (بني)
4. ثانوية الأوائل المتميزين (أخضر)
5. ثانوية الأوائل المتميزات (أخضر زمردي)
6. مدرسة الأوائل البريطانية الدولية (أزرق)

## التشغيل المحلي (Local Run):
```bash
npm install
npm start
```
يفتح على: `http://localhost:3000`

## النشر على Render:
المشروع جاهز فوراً للنشر على منصة Render عبر ملف `render.yaml`.
- Build Command: `npm install`
- Start Command: `node server.js`
